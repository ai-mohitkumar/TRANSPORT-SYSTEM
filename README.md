# 🚚 Transport System Management (Python)

A **Transport System Management System** developed using **Python** that helps manage transportation services such as user records, route allocation, and billing efficiently.

---

## 📌 Overview

This project is a **menu-driven application** built in Python to automate transport-related operations. It replaces manual record-keeping with a digital system that improves accuracy, speed, and usability.

---

## ✨ Features

* 👤 **User Management**

  * Add new users
  * Delete users
  * View user details

* 🗺️ **Route Management**

  * Assign routes based on location/district
  * Manage transport allocation

* 💰 **Billing System**

  * Calculate transport charges
  * Generate payment details

* 🔐 **Admin Control**

  * Secure and controlled access

* 💾 **Data Storage**

  * File handling using Python

---

## 🛠️ Tech Stack

* **Language:** Python 🐍
* **Interface:** Command Line Interface (CLI)
* **Concepts Used:**

  * Functions
